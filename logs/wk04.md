# css 
# Line 1: gap: 0.5rem 1rem;
- It sets the space between menu items. The first number (0.5rem) is the space between rows, and the second number (1rem) is the space between columns, meaning side by side.

# Line 2: nav a:hover, nav a[aria-current="page"] { text-decoration: underline; }
- [aria-current="page"] means a link is underlined if it has that label in the HTML, which marks the page you're currently on. The comma means the underline applies in both cases.

# Line 3: margin: 0 auto;
- The first value is the top and bottom margin. The second value is the left and right margin (auto), which means share the space equally. That pushes the content into the center of the screen.

# What changed on screen 
I changed margin: 0 auto to margin: 0 on main. The Coming Soon box jumped from the center of the page to the left edge, leaving a large empty gap on the right. That shows auto is what does the centering.
