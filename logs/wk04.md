# Something new I picked up
- Cascading override: a class selector like .intro beats a tag selector like p even if the tag rule is later, but if they're equally specific the later one wins
- Flexbox is one-dimensional (rows or columns), Grid is two-dimensional, that's the actual difference
- The dev workflow order: intent → proposal.md → PRD.md (AI-generated) → agents.md → then build, plain HTML/CSS/JS only for Project 1
- Online ordering with payment is the hardest feature to build, so it gets deferred to a next version instead of forced into v1
