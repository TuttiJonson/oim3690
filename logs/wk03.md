# Something new I picked up
- External CSS is the preferred way because one file controls every page, so the whole site stays consistent. 
- Class selectors (.name) are reusable, while ID selectors (#name) must be unique, so the rule is to use classes everywhere and IDs only for in-page anchor links.
- Font stacks list backup fonts in case the first one isn't on the user's device, and you can find what font any website uses with right-click -> Inspect -> Styles.
- Semantic tags (header, nav, main, footer) matter because screen readers and reading modes use them to navigate, and headings shouldn't skip levels (h1 -> h2 -> h3).

```css
/* Rule 1: my h1 */
/* This changes every h1 on my page. */
h1 {
  color: #1e3a8a;      /* makes the heading navy blue */
  font-size: 2.5rem;   /* makes it bigger, I think rem is based on the page's normal text size */
  text-align: center;  /* puts the heading in the middle */
}

/* Rule 2: a class I made up */
/* The dot means it's a class. It only works if I add class="highlight-box" to something in my HTML. */
.highlight-box {
  background-color: rgb(235, 240, 250);  /* a really light blue background */
  border-left: 5px solid #1e3a8a;        /* a navy line on the left side only */
  padding: 16px;                         /* space between the text and the edge of the box */
  border-radius: 8px;                    /* rounds the corners */
}

/* Rule 3: a:hover */
/* This makes links change when my mouse goes over them. I didn't have to add anything to my HTML for this one. */
a:hover {
  color: orange;              /* link turns orange when I hover */
  text-decoration: underline; /* adds a line under it */
}

/* Rule 4: the conflict */
/* I wrote a second h1 rule on purpose to see which color wins. */
h1 {
  color: purple;  /* this won because it's lower in the file than the navy one */
}
```

- When I opened DevTools (right-click -> Inspect -> Styles), I saw the navy color crossed out and purple was the one being used. So when two rules are the same, the one written later wins.
- Then I added class="title" to my h1 and wrote a .title rule with crimson ABOVE both h1 rules. Crimson still won, even though it came first. I think this is because a class is more specific than just the tag name, so "the later one wins" only works when the rules are equally specific.
