# Something new I picked up
- After the first HTML request, every font, image, and stylesheet is its own separate HTTP request, and they get cached locally for however long max-age says
- The S in HTTPS is an encryption layer so traffic is unreadable even if someone intercepts it
- pull brings Github changes to you 
- Once you commit to main Github Deskitop, the repo change is on your own computer and not on github where others can see it. 
- I thought that gitigore hides it, but actually it only stays in your computer and Giithub doesn't ignore it 
- You can test out things on Common Tags, to help you visualize how it would look in your website.
